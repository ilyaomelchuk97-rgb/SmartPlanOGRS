Как работает автоподбор работ в «Графике работ»

SmartPlan · УП «МИНГАЗ» · сборка 22.09-306 · правила сборок 278–306
Открывается из окна «Настроить периодичность» — серая круглая кнопка i рядом с заголовком: схема показывается окном поверх страницы (закрыть — кнопкой × или клавишей Esc; список прокручивается внутри окна).
Схема отражает то, что реально делает программа: правила сверены с кодом и проверены прогонами на рабочем справочнике. Учтены правила сборок 278–306 (эксплуатация, одна работа на группу, сезон, REGION-gaz, настройки по группам для телеметрии и отопления, котлы).
Как читать схему: — шаг, который ведёт дальше — здесь работа/объект отсеивается — этап РЕШЕНИЕ — вопрос «да / нет»
ЭТАП 1 · Проверка объекта (сборка 278)
Объект в строке графика (например, ГРП-1, ул. Ленина, 5)
▼
РЕШЕНИЕТип объекта — ГРП / ШРП / ПГРП?
ДА → идём к проверке статуса ниже.
НЕТ (Трасса, Просека, Область…) → правила статуса к таким объектам не применяются — подбор идёт как раньше.
▼
РЕШЕНИЕСтатус объекта = «В эксплуатации»?
ДА → переходим к ЭТАПУ 2.
НЕТ — объект выведен (Проектируется, Строится, Реконструкция, Консервация, Ликвидирован): работы не назначаются; при сохранении невыполненные задачи его серий убираются, выполненные остаются в истории, а периодичность работ сохраняется. Вернули в эксплуатацию — серия начинается заново от даты возврата. В графике объект помечен значком ⛔.
НЕТ — статус не задан: новые работы не назначаются, но уже поставленные задачи не удаляются. На странице графика — предупреждение и кнопка «Статусы объектов» (статус ставится в один клик, в т.ч. «✓ Всем без статуса — В эксплуатации»). В графике объект помечен значком ❓.
▼
ЭТАП 2 · Перебор работ справочника (кнопка «⚡»; работы берутся в порядке списка справочника)
Очередная работа справочника участка (виды работ того участка, что выбран в окне: по умолчанию — участок графика)
▼
РЕШЕНИЕРабота из списка «не подбирать никогда»?
НЕТ → дальше.
ДА → пропуск. В этот список занесена работа «Текущий ремонт оборудования шкафных газорегуляторных пунктов без опрессовки» — её назначают только вручную («+ работа»).
▼
РЕШЕНИЕВ группе этой работы у объекта уже есть работа? (одна работа на группу)
НЕТ → проверяем по критериям ниже.
ДА → пропуск: в строке объекта уже есть работа этой группы (или она добавилась минуту назад), вторую не берём.
▼
РЕШЕНИЕСовпали ли характеристики работы и объекта? (5 критериев — галочки в окне, по умолчанию все включены)
ДА → работа добавляется у объекта строкой, её группа запоминается (другие работы этой группы больше не рассматриваются), идём к следующей работе справочника.
НЕТ → пропуск, идём к следующей работе.
Сезон здесь НЕ отсеивает работу: зимние и летние версии нужны, чтобы график сам подставлял нужную по датам (ЭТАП 3).
▼
Строка добавлена: периодичность и отклонение — из карточки работы; дата первого проведения — по «Реквизиту отсчёта» работы: «от предыдущей даты» (по умолчанию пусто), «от даты ввода в эксплуатацию» (переносится в год графика), «от даты окончания срока службы» (разово — к самой дате).
▼
ЭТАП 3 · Вы нажимаете «Сохранить» — расстановка дат и задач (сборки 279/280)
РЕШЕНИЕДата попадает в зимний период графика? (период задаётся кнопкой ❄ «Сезоны»; учитываются только день и месяц)
ДА (это «зима») → берём зимнюю версию работы из её группы (например, «Тех. осмотр ГРП 2-ниточного путем обхода зимой тел.»).
НЕТ (остальное время) → берём летнюю/обычную версию («…путем обхода летом тел.»); если явной летней нет — работа без сезона («Круглый год»).
Приоритет версий: сначала — работа, у которой сезон явно совпал с датой (зимой — зимняя, летом — летняя), затем — работа без сезона. Если у работ группы сезон задан, а версии для этого периода нет — вхождение пропускается (в отчёте: «Пропущено вхождений по сезону»).
Если зимний период в графике не задан: зимние работы не ставятся вовсе, летние и работы без сезона идут весь год.
▼
РЕШЕНИЕТакая задача уже есть в «Планировании»? (тот же объект + та же работа + та же дата)
НЕТ → создаём задачу.
ДА → дубль не создаём: серия привязывается к существующей задаче (в отчёте: «уже были в планировании»).
▼
Дата ставится на ближайший предыдущий рабочий день мастера графика (график смен — вкладка «Работники»), шаг серии при этом считается от исходной даты.
Задача в «Планировании»: дата = дата вхождения, дедлайн = дата + отклонение, исполнители — слесаря бригады мастера. Прошедшие даты: задачи создаются только если у объекта включено «Добавлять задачи на прошедшие дни» (в графике остаются треугольники).
▼
Следующая дата серии = текущая + периодичность − отклонение (пример: 1 мес и отклонение 2 дня — работа 18-го числа → следующая 16-го следующего месяца).
Внизу окна появляется отчёт: сколько задач создано/убрано, сколько вхождений переключено по сезону, сколько пропущено по сезону и сколько объектов пропущено как «не в эксплуатации» / «без статуса».
Ручные исключения: строка, выбранная кнопкой 🎯 («точный выбор работы в группе»), помечается как ручная и по сезону не переключается; работы можно добавить и вручную кнопкой «+ работа» — в обход этих правил.
Когда это происходит. Даты и сезонные версии пересчитываются в трёх случаях: ① нажали «Сохранить» в «Настроить периодичность»; ② изменили год графика в «Списке графиков»; ③ нажали «Сохранить» в окне ❄ «Сезоны» (тогда версии работ переключаются сразу, без пересохранения периодичности). Прошедшие даты отражаются в графике треугольниками всегда, а задачи в «Планировании» по ним создаются только при включённом «Добавлять задачи на прошедшие дни». Если у работы периодичность не задана, строка добавится, но серии дат не будет — пока не зададите периодичность и дату первого проведения.

Пять критериев сравнения (ЭТАП 2, «да/нет» по характеристикам)

№ Галочка в окне Что у работы Что у объекта Если у объекта пусто
1 по типу объекта «Категория объекта обслуживания» (ГРП/ШРП/ПГРП) тип объекта (ГРП / ШРП / ПГРП) работа с категорией не подойдёт, работа без категории — подойдёт
2 по линиям редуцирования «Кол-во линий редуцирования» (если задано) «Кол-во линий редуцирования» работы «по линиям» не подбираются
3 по телеметрии «Телеметрия на объекте» / «Тип телеметрии»; работы по ТМ распознаются по названию, а также по отметке группы в настройках автоподбора (⚙) «Тип телеметрии» (наличие и название) работы по ТМ не подойдут; работы «без телеметрии» — подойдут
4 по виду обслуживания отметка «диагностика» или группа работы отмечена в настройках автоподбора (⚙ в справочнике ГРП) «Вид обслуживания»: REGION-gaz = приборно-диагностический комплекс (или «Без ИПК») у объекта REGION-gaz подбираются «диагностика» и выбранные группы; обычным объектам «диагностика» не подойдёт
5 по отоплению «ТО отопительного оборудования» (если у работы указан вид отопления — он должен совпасть), а также группы, отмеченные в настройках автоподбора (⚙) «Вид отопления»: «Газовое» = на объекте есть котёл (у ШРП отопления нет) работы «ТО отопительного» не подойдут; при «Электрическое» — тоже не подойдут
Правило REGION-gaz (сборка 290): отметка «диагностика» — только для объектов с приборно-диагностическим комплексом. Объекту с REGION-gaz автоподбор назначает работы «диагностика» и работы групп, отмеченных в настройках автоподбора — они открываются кнопкой ⚙ в шапке справочника участка ГРП — у неё белый фон и оранжевый контур (страница «Справочники»). Если не отмечено ни одной группы, такому объекту подбирается только «диагностика». Остальным объектам все работы подбираются как обычно.
Настройки по группам для телеметрии и отопления (сборка 296). В том же окне ⚙ (шапка справочника участка ГРП) появились ещё два списка групп — такие же, как для REGION-gaz:
· 📡 Работы по телеметрии — работы отмеченных групп подбираются только объектам с телеметрией;
· 🔥 Работы по отоплению (котёл) — работы отмеченных групп подбираются только объектам с «Вид отопления» = «Газовое».
Отметки дополняют карточку работы: если телеметрия или отопление указаны в карточке (или распознаются по названию) — работа учитывается и без отметки; отметка закрывает случаи, где в карточке ничего не задано. Если правило работы указано явно — оно главнее отметки в группе. Все три списка действуют только на «⚡ Автоподбор» и на сохранение графика.
Что можно настроить самому (окно ⚙, сборки 290 и 296). Кнопка ⚙ — в шапке справочника участка ГРП (видна администратору). В окне две части: три списка групп — «Работы для объектов REGION-gaz», «📡 Работы по телеметрии», «🔥 Работы по отоплению (котёл)» — и пять галочек «Критерии сравнения» (тип объекта, линии редуцирования, телеметрия, вид обслуживания, отопление). Настройки сохраняются на сервере (раздел settings, запись autopick), действуют на всех устройствах и у всех пользователей и применяются и при «⚡ Автоподборе», и при сохранении графика.
Не настраивается (так и задумано): «одна работа на группу»; работа «текущий ремонт оборудования шкафных газорегуляторных пунктов без опрессовки» — никогда не подбирается; работы «диагностика» — всегда только объектам REGION-gaz; сезон берётся из карточки вида работы (или из названия), а не из групп; окно ⚙ работает только для участка ГРП.
Совместные работы — в один день (сборки 304 и 306). Если у работ указано «Проводится совместно» (связь по группам или по самим видам работ), программа ставит их в один и тот же день внутри месяца: берётся самая ранняя дата из сегодняшних и будущих и на неё переносятся остальные работы группы.
· Связь соединяется цепочкой: если A проводится совместно с B, а B — с C, то A, B и C встанут в один день.
· Отметка родительской группы действует и на вложенные подгруппы («Группа / Подгруппа») — раньше сравнение было строгим, и такие работы не соединялись.
· В инструментах графика есть кнопка 🤝 «Соединить совместные»: по нажатию все совместные работы графика ставятся в один день, а в сообщении видно, сколько работ соединено.
· После ручного переноса задачи подтягиваются её совместные работы этого месяца; после сохранения «Сезонов» совместные выравниваются заново.
· Выполненные работы остаются в истории: их не переносят; будущие работы никогда не подтягиваются к прошедшему дню.
Отопление и котёл (сборка 282). «Вид отопления» = «Газовое» означает, что на объекте есть газовый котёл: только таким объектам подбираются работы «ТО отопительного оборудования». Объектам без отопления и с «Электрическое» эти работы не назначаются — даже если в названии работы вид котла не указан.

Если поля карточки работы пустые — связь распознаётся по названию

в названии есть «ИНДЕЛ»работа только объектам с телеметрией этого типа
«оборудованных системой телеметр…» / «ТМ и АСУТП» / «(ТМ)» / «телемеханики»работа по телеметрии — только объектам с ТМ
«не оборудованных системой телеметр…»только объектам без телеметрии
«приборного диагностического оборудования»диагностика — только объектам REGION-gaz
«отопительного» / «газовых котлов» / «электрокотлов»только объектам с отоплением (и по виду отопления)
«…путем обхода летом…» / «…зимой…»летняя / зимняя версия работы (для переключения по датам)
пометки группы работ 🏷 «Работы с ТМ» / «Без телеметрии»то же самое, но задано на всю группу сразу

Пример: как это сработает на вашем справочнике

Названия работ взяты из вашей базы; результат проверен прогоном правил, а не «на словах».
Объект А: ГРП, 2 линии, телеметрия «ПТК "Индел"», вид обслуживания REGION-gaz, отопление газовое, «В эксплуатации»
✓ ТО с приборным диагностическим оборудованием, 2 линии
✓ Тех. осмотр «…путем обхода летом тел.» (зимой встанет парная «зимой тел.»)
✓ Текущий ремонт оборудования системы телеметрии (ТМ)
✓ Текущий ремонт ГРП с опрессовкой — подбирается как обычно (диагностика его не заменяет)
Объект Б: ГРП, 2 линии, без телеметрии, вид обслуживания не задан, без отопления, «В эксплуатации»
✓ Текущий ремонт ГРП с опрессовкой
✓ Очистка территории от снега (сезон «Зима») — встанет только в зимний период
✕ ТО с приборной диагностикой — нет REGION-gaz
✕ Тех. осмотр с ТМ — у объекта нет телеметрии
✕ ТО газовых котлов — нет котла: «Вид отопления» не «Газовое»

Что автоподбор не делает — это только вручную

• «+ работа» — добавить работу, которую автоподбор не подобрал (например, зимнюю до задания зимнего периода).
• 🎯 — точный выбор конкретной работы внутри группы; такая строка помечается как ручная и не переключается по сезону.
• Работа «Текущий ремонт оборудования шкафных газорегуляторных пунктов без опрессовки» — не подбирается никогда.
• Объекты не в эксплуатации и объекты без статуса — работы им автоподбор не назначает (см. ЭТАП 1).
• Если объект в эксплуатации, но у него не заполнены линии/телеметрия/отопление/вид обслуживания — соответствующие группы работ просто не подберутся: заполните атрибуты в карточке объекта.
• Сезон работ по группам не настраивается: он берётся из карточки вида работы (или распознаётся по названию) — группы сезон не задают.
• Настройки ⚙ действуют для участка ГРП; на других участках автоподбор устроен иначе (у них свои правила и атрибуты).
Как повторить подбор самому: «График работ» → кнопка ❄ «Сезоны» (задать зимний период) → «Настроить периодичность» → кнопка «⚡ Подобрать всем объектам» (или «⚡» у отдельного объекта) → «Сохранить». Внизу окна появится отчёт: добавлено работ, создано задач, переключено по сезону, пропущено по сезону и пропущено объектов (не в эксплуатации / без статуса).
